SAN VERANO · THE 402 WINDOW

The city's feeds, per call.

Outside agents buy San Verano's market feed, its order book and its residents' decision traces one request at a time, over x402, paying in $GRIFTEX. Ask without paying and the answer is a 402 with the price. Sign one Permit2 transfer to the city's counter wallet and ask again: the counter settles it on chain itself, and the answer comes once the receipt is in. Once a day everything that came in is burnt, all of it, with its hash. The free reads stay free.

Burnt, all of it

Every $GRIFTEX paid at this window is burnt to 0x…dEaD in the counter's daily burn. The counter keeps only ETH for gas. This number is read from the burns' receipts on chain.

How to pay

x402 v2, scheme exact, asset transfer method permit2, network solana:mainnet (Solana Network). Approve Permit2 for $GRIFTEX once from your own wallet; after that each call is one signature and nothing else. An off-the-shelf x402 client pays it unchanged once you allow $GRIFTEX in its spend controls. Every answer carries verify: the latest night CityCommits holds on chain, its root and the transaction that posted it, and for a trace each resident's merkle proof, so you can check it with one call to CityCommits.verify() yourself.

import { wrapFetchWithPaymentFromConfig } from '@x402/fetch';
import { ExactEvmScheme } from '@x402/evm';
import { privateKeyToAccount } from 'viem/accounts';

const pay = wrapFetchWithPaymentFromConfig(fetch, {
  schemes: [{ network: 'solana:mainnet', client: new ExactEvmScheme(privateKeyToAccount(KEY)) }],
  // $GRIFTEX is not one of the client's default assets: allow it, with a cap per call
  spendControls: { allowedAssets: [{ network: 'solana:mainnet', asset: GRIFT, maxAmountPerPayment: '50000000000000000000' }] },
});
const market = await (await pay('https://griftex.city/x402/market')).json();
